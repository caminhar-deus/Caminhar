# ADR-NNNN: Título curto e específico

> **Padrão de data:** para decisão nova, preencha o campo Data com a data da
> decisão. Quando a data original da decisão for desconhecida (decisões
> retroativas), use **"Registrado em: AAAA-MM-DD"**.

- **Status:** Proposto
- **Data:** AAAA-MM-DD *(ou "Registrado em: AAAA-MM-DD", conforme a nota acima)*
- **Decisores:** (opcional) nomes ou papéis
- **Relacionados:** ADR-XXXX, issue ou PR, arquivos do repositório

> Status possíveis: Proposto | Aceito | Rejeitado | Obsoleto | Substituído por ADR-NNNN

## Contexto

Qual problema ou força motivou a decisão? Descreva fatos e restrições, com links
para código, issues ou PRs. Não proponha a solução aqui. Nunca invente motivação:
se o porquê não estiver documentado, diga isso explicitamente.

## Decisão

O que foi decidido, em voz ativa. Exemplo: "Vamos usar X para Y."

## Alternativas consideradas

Inclua as alternativas avaliadas quando houver registro delas. **Quando não
houver registro de alternativas à época, escreva isso explicitamente em vez de
inventar** — para decisões retroativas isso é preferível a uma lista plausível
e falsa.

- **Opção A:** por que foi descartada.
- **Opção B:** por que foi descartada.
